QUE HACER

1. leer todos los documentos
2. De acuerdo a la lectura definir 10 artefactos A2UI para usar en el chat (Líneas de tiempo, formulario, grafica, tarjetas, animaciones, slides, etcetera, según se requiera)
3. hacer ajustes en interfaz de chat para que los elementos A2UI se muestren adecuadamente.
4. para que el formulario funcione, haz que envíe la información usando formspree con este enlace https://formspree.io/f/mzdyzqwb
5. Si es necesario crea los archivos que se requieran: .json, .py, .md, y los demás que sean necesarios.
6. asegura que esto siempre funcione con el chat.
7. tienes el mcp de GitHub para subir los archivos, úsalo.
